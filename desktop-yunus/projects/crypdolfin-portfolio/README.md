## 🇹🇷 Türkçe Açıklama

### Özellikler
- **Bento Grid Tasarımı**: Modern, esnek ve tamamen duyarlı (responsive) bento yerleşimi.
- **Etkileşimli Araçlar**: ROI hesaplayıcı ve özel hizmet paketi modalları.
- **Firebase Analytics & Event Tracking**: Ziyaretçi davranışlarını ölçümlemek için optimize edilmiş event tracking yapısı.
- **WhatsApp ve Sosyal Entegrasyonlar**: Hızlı erişim için tasarlanmış WhatsApp butonu (FAB) ve sosyal medya bağlantıları.

### Kurulum ve Çalıştırma
Projeyi yerelde çalıştırmak için:
```bash
# Projeyi çalıştırın (Herhangi bir statik sunucuyla)
npx serve .
```

### Firebase Dağıtımı (Hosting)
1. Firebase CLI araçlarını yükleyin ve giriş yapın:
   ```bash
   npm install -g firebase-tools
   firebase login
   ```
2. Canlıya deploy edin:
   ```bash
   firebase deploy --only hosting
   ```

## 🇬🇧 English Description

### Features
- **Bento Grid Layout**: Sleek, modular, and fully responsive grid styling.
- **Interactive Tools**: Built-in ROI calculator and custom service package modals.
- **Firebase Analytics & Event Tracking**: Automated tracking for CTA clicks, WhatsApp visits, and contact forms.
- **Premium UI/UX**: Dark mode layout with neon glassmorphism and smooth transitions.

### Installation
To run the project locally:
```bash
# Run with any static server
npx serve .
```

### Firebase Hosting Deploy
```bash
firebase deploy --only hosting
```
